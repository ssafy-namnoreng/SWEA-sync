# SWEA → 팀 레포 자동화 (`swea_sync.py`)

SWEA Solving Club의 그날 문제 목록을 읽어서, 우리 조 폴더에

```
daily/<날짜>/<팀>/SWEA-<번호>/
├── readme.md          ← # 제목 난이도  +  ## [바로가기](링크)   (끌 수 있음)
└── <SWEA 원본 파일명>.txt  ← 사이트에서 받은 sample input 그대로
```

폴더 구조는 원하는 대로 바꿀 수 있고(`{클럽}/{박스}` 등), 폴더 이름에 문제 제목과
문제 박스 이름을 넣을 수도 있습니다. 문제가 여러 페이지에 걸쳐 있어도 전부 받습니다.

```
SWEA-1974-스도쿠 검증/                       ← 폴더에제목 = 예
SWEA-4875(Stack2_1)-...5일차 - 미로/         ← + 폴더에박스 = 예
```

를 한 번에 만들어 줍니다.

생성되는 `readme.md`는 지금 team-E가 쓰는 포맷 그대로입니다 (UTF-8 / CRLF):

```markdown
# 스도쿠 검증 D2

## [바로가기](https://swexpertacademy.com/main/talk/solvingClub/problemView.do?...)
```

## 1. 설치 (처음 한 번만)

필요한 것: **Python 3.9 이상** 하나뿐입니다. (개발/확인 환경은 3.12.10)

**`START.bat` 을 더블클릭하면 나머지는 알아서 합니다.** 처음 실행하면 이렇게 묻습니다.

```
  처음 실행이라 필요한 것을 몇 개 설치해야 합니다.
     - playwright>=1.44    SWEA 페이지를 읽고 파일을 받는 데 필요
     - rich>=13            콘솔 화면을 보기 좋게 그리는 데 필요
     - questionary>=2      설정을 방향키로 고르는 데 필요

  지금 설치할까요? [Y/n]
```

Enter 만 누르면 설치하고 이어서 진행합니다.

**브라우저도 따로 받지 않습니다.** PC 에 이미 있는 Chrome 이나 Edge 를 찾아서 씁니다.
(둘 다 없을 때만 Chromium 을 받겠냐고 묻습니다)

직접 설치하고 싶으면:

```bash
pip install -r requirements.txt
```

### 설치 확인

```bash
python swea_sync.py --help
```

도움말이 뜨면 설치 완료입니다.

## 2. 설정

**처음 실행하면 물어봅니다.** 설정 파일을 미리 열 필요가 없습니다.

```
  몇 가지만 정하면 됩니다.

  프로필 이름
> 이름  기본

  저장 위치
> 경로  C:/Users/내계정/PycharmProjects/algorithm
  확인했습니다. daily 폴더가 있습니다.
> 이 경로가 맞나요? (Y/n)

  폴더 구조
> 어떤 구조로 할까요?
   daily/{날짜}/{팀}             기본. 반 레포 규칙
   {클럽}/{박스}                 클럽 이름 / 문제 박스 이름
   {팀}/{날짜}                   조별로 모아두기
   ...

  우리 조                       ← 구조에 {팀} 이 있을 때만 묻습니다
> 조  team-E
```

### 프로필 — 레포마다 설정 한 벌

설정은 **프로필** 단위로 저장됩니다. 프로필 하나 = 레포 경로 + 그 경로에서 쓰는 설정 전부.
반 레포는 `daily/{날짜}/{팀}` 으로, 개인 정리용 레포는 `{클럽}/{박스}` 로, 이렇게
**레포마다 다른 구조·설정을 나눠 둘 수 있습니다.**

```
profiles/
├── _current.txt     ← 지금 쓰는 프로필 이름
├── 기본.txt          ← 반 레포용
└── 개인정리.txt      ← 내 레포용
```

메뉴의 **'프로필'** 에서 전환 · 새로 만들기 · 삭제를 합니다. 새 프로필은 지금 프로필의
취향 설정(readme, 창숨김 등)을 물려받고 경로·구조·팀만 새로 묻습니다.

```bash
python swea_sync.py --profile 개인정리     # 이번 실행만 다른 프로필로
```

> 예전 버전(`settings.txt` 하나)을 쓰던 분은 처음 실행할 때 자동으로
> `profiles/기본.txt` 로 옮겨집니다. 아무것도 안 하셔도 됩니다.
>
> `profiles/` 안에는 개인 경로가 들어 있으니 **git 에 올리지 마세요** (`.gitignore` 에 넣어뒀습니다).

경로는 **실제로 있는 폴더인지 확인하고**, 아니면 이유를 알려주고 다시 묻습니다.

- 따옴표가 붙어 있어도 알아서 뗍니다 (탐색기에서 "경로 복사" 하면 붙습니다)
- 역슬래시든 슬래시든 됩니다
- `algorithm/daily` 를 고르면 상위 폴더로 잡아줍니다
- 상위 폴더를 고르면 그 아래 `daily` 가 있는 폴더를 찾아줍니다
- `daily` 폴더가 안 보이면 알려주되 진행은 할 수 있습니다

고른 경로를 다시 보여주고 **맞는지 확인**한 뒤 `settings.txt` 에 저장합니다.
나중에는 메뉴의 **'설정 바꾸기'** 에서 언제든 고칠 수 있습니다.

### 파일로 직접 고치기 (`profiles/<이름>.txt`)

메모장으로 열어서 `키 = 값` 만 고쳐도 됩니다. `#` 으로 시작하는 줄은 주석입니다.
(`settings.txt` 는 새 프로필을 만들 때 복사하는 템플릿이라 실제 설정은 아닙니다)

```ini
경로       = C:/Users/내계정/PycharmProjects/algorithm
팀         = team-E
날짜       =
폴더구조   = daily/{날짜}/{팀}
폴더에제목 = 아니오
폴더에박스 = 아니오
폴더이름갱신 = 아니오
readme     = 예
창숨김     = 아니오
문제목록   =
포트       = 9222
```

| 키 | 설명 |
|---|---|
| `경로` | 문제 폴더들을 만들어 넣을 최상위 폴더. **필수 — 각자 자기 경로로** |
| `팀` | 자기 조 폴더명 (`team-A` ~ `team-E`). `폴더구조` 에 `{팀}` 이 있을 때 필수 |
| `날짜` | `daily/<날짜>` 로 들어갈 날짜. **비워두면 오늘 날짜**. 지난 날짜를 채울 때만 `2026-09-01` 형식으로 입력 |
| `폴더구조` | 문제 폴더들이 들어갈 위치. `{날짜} {년} {월} {일} {팀} {클럽} {박스}` 사용. 기본 `daily/{날짜}/{팀}` |
| `폴더에제목` | `예` 로 두면 폴더명이 `SWEA-1974-스도쿠 검증` 처럼 제목까지 붙음. 기본은 `SWEA-1974` |
| `폴더에박스` | `예` 로 두면 폴더명에 문제 박스 이름이 붙음 (`SWEA-4875(Stack2_1)`) |
| `readme` | `아니오` 로 두면 `readme.md` 를 만들지 않고 문제 폴더와 input 만 받음 |
| `폴더이름갱신` | `예` 로 두면 이미 만들어 둔 폴더 이름도 지금 설정에 맞게 바꿈 (확인 후) |
| `창숨김` | `예` 로 두면 크롬 창을 띄우지 않고 조용히 실행. `문제목록` 이 함께 필요 |
| `문제목록` | 그날 문제 박스 주소. 창숨김 모드에서 필수 |
| `브라우저프로필` | 로그인 세션 저장 위치. 비워두면 `~/.swea_sync/chrome-profile` |
| `포트` | 자동화용 브라우저 디버깅 포트. 충돌 나면 다른 번호로 |

**값을 비워두면 기본값이 쓰입니다.** 특히 `날짜` 는 평소엔 비워두세요.

키 이름은 한글/영문 아무거나 됩니다 (`경로` = `repo` = `repo_path` = `path`,
`팀` = `조` = `team`, `날짜` = `date`). 띄어쓰기가 섞여도 알아듣습니다.

### 명령줄로 한 번만 덮어쓰기

`settings.txt` 를 안 고치고 이번 실행만 다르게 하고 싶을 때:

```bash
python swea_sync.py --date 2026-09-01     # 어제 것 채워 넣기
python swea_sync.py --team team-C         # 다른 조
python swea_sync.py --repo "D:/다른경로/algorithm"
```

우선순위는 **명령줄 옵션 > `settings.txt` > 기본값** 입니다.

## 3. 사용법

### 가장 쉬운 방법 — `START.bat` 더블클릭

**`START.bat` 하나만** 더블클릭하면 메뉴 화면이 뜹니다.

```
  SWEA 문제 폴더 자동 생성기

╭─ settings.txt ──────────────────────────────────────────────╮
│                                                             │
│       경로  C:/Users/내계정/PycharmProjects/algorithm        │
│         팀  team-E                                          │
│       날짜  2026-09-10  (오늘)                               │
│   폴더이름  SWEA-<번호>(<박스>)-<제목>                        │
│     readme  만듦                                            │
│   브라우저  창 띄움                                          │
│                                                             │
╰─────────────────────────────────────────────────────────────╯

> 무엇을 할까요?  (방향키로 고르고 Enter)
 > 실행하기 - 폴더와 파일을 만듭니다
   미리보기 - 파일은 안 만들고 확인만
   설정 바꾸기
   끝내기
```

**설정 파일을 열 필요가 없습니다.** '설정 바꾸기' 에서 방향키로 고르고 고치면
파일에 그대로 저장됩니다 (주석은 건드리지 않습니다).

설정은 **위치 · 폴더 이름 · 만드는 것 · 실행** 네 묶음으로 나뉘어 있고, 방향키로
항목에 가면 **그 설정이 무엇인지 아래에 한 줄 설명**이 뜹니다.

```
> 무엇을 바꿀까요?
  ── 위치 ──
 > 경로               C:/Users/내계정/PycharmProjects/algorithm
   폴더 구조          {클럽}/{박스}
   팀                 team-E
  ── 폴더 이름 ──
   문제 제목 넣기     예
   ...
  문제 폴더들을 만들어 넣을 최상위 폴더입니다.   ← 설명
```
한 항목을 고쳐도 설정 화면에 그대로 머물러서 연달아 바꿀 수 있고,
'돌아가기' 를 골라야 메인으로 나옵니다.

화면은 넘어갈 때마다 지우고 다시 그립니다. 출력이 아래로 쌓이지 않습니다.

명령줄 옵션을 하나라도 주면 메뉴 없이 바로 실행합니다. 배치나 예약 실행에서
메뉴가 떠서 멈추는 일이 없도록 한 것입니다. `--no-menu` 로 강제할 수도 있습니다.

### 명령줄로 쓰기

```bash
python swea_sync.py
```

1. **처음 실행하면** 전용 크롬 창이 새로 뜹니다 → 여기서 SWEA에 로그인하세요.
    - 평소 쓰는 크롬과 **별개의 창**입니다 (프로필이 다름). 평소 크롬의 탭·북마크는
      건드리지 않고, 반대로 평소 크롬의 SWEA 로그인도 여기로 넘어오지 않습니다.
    - 이 창은 스크립트가 끝나도 **닫히지 않습니다.** 창을 열어두는 동안에는
      다시 로그인하지 않아도 됩니다.
    - 다만 SWEA 로그인은 **오래 유지되지 않습니다.** 창을 닫거나 한참 뒤에 다시 쓰면
      로그아웃돼 있을 수 있습니다. 그럴 땐 뜬 창에서 다시 로그인하면 됩니다.
2. 그 창에서 **오늘 풀 문제 박스(문제 목록) 페이지**를 열어둡니다.
3. 터미널로 돌아와 Enter → 문제를 하나씩 돌면서 폴더 · `readme.md` · input 파일 생성.

**두 번째 실행부터는** 그 창이 이미 떠 있으므로, 오늘 문제 박스만 띄워두고
`python swea_sync.py` 만 치면 열린 탭을 알아서 인식합니다.

### URL을 직접 주는 방식

문제 박스 이름이 날마다 제각각이라 자동 탐색은 하지 않습니다.
탭을 띄우기 싫으면 URL을 그대로 붙여넣으면 됩니다.

```bash
python swea_sync.py "https://swexpertacademy.com/main/talk/solvingClub/problemBox.do?...&probBoxId=BBBBboxIdBBBB"
```

### 자주 쓰는 옵션

| 옵션 | 설명 |
|---|---|
| `--date 2026-09-02` | 다른 날짜 폴더에 생성 (기본: 오늘) |
| `--team team-C` | 다른 조 폴더 |
| `--dry-run` | 파일은 안 쓰고 무엇을 만들지만 출력 — **처음엔 이걸로 먼저 확인** |
| `--force` | 이미 있는 `readme.md` / input 파일도 덮어쓰기 |
| `--inspect` | 페이지 HTML·링크를 덤프 (아래 문제 해결 참고) |
| `--folder-title` / `--no-folder-title` | 이번 실행만 폴더명에 제목 넣기/빼기 |
| `--folder-box` / `--no-folder-box` | 이번 실행만 폴더명에 박스 이름 넣기/빼기 |
| `--no-readme` | 이번 실행만 `readme.md` 안 만들기 |
| `--rename-folders` / `--no-rename-folders` | 이번 실행만 기존 폴더 이름 갱신 켜기/끄기 |
| `--layout "{클럽}/{박스}"` | 이번 실행만 다른 폴더 구조로 |
| `--profile 이름` | 이번 실행만 다른 프로필로 (`profiles/` 안의 것) |
| `--menu` / `--no-menu` | 메뉴 화면을 띄우기 / 띄우지 않기 |
| `-y`, `--yes` | 설치 여부를 묻지 않고 진행 |
| `--headless` | 이번 실행만 창숨김으로 |
| `--show` | 이번 실행만 창을 띄움 (로그인할 때) |

```bash
# 안전하게 먼저 확인
python swea_sync.py --dry-run
# 문제 없으면 실제 실행
python swea_sync.py
```

### 폴더 구조를 내 방식으로

```ini
폴더구조 = {클럽}/{박스}
```

문제 폴더들이 들어갈 위치를 정합니다. 레포 기준 상대 경로이고, 중괄호 자리표시자를 씁니다.

| 자리표시자 | 값 |
|---|---|
| `{날짜}` | `2026-09-11` |
| `{년}` `{월}` `{일}` | `2026` `09` `11` |
| `{팀}` | `team-E` |
| `{클럽}` | Solving Club 이름 (예: `16기 서울 4반 역량테스트 대비 문제리스트`) |
| `{박스}` | 문제 박스 이름 (예: `IM 대비 추천 문제`) |

```
daily/{날짜}/{팀}          ->  daily/2026-09-11/team-E/SWEA-4875...      (기본, 반 레포 규칙)
{클럽}/{박스}              ->  16기 서울 4반 .../IM 대비 추천 문제/SWEA-4875...
{팀}/{날짜}                ->  team-E/2026-09-11/SWEA-4875...
{년}/{월}/{일}/{팀}        ->  2026/09/11/team-E/SWEA-4875...
```

- 영문(`{date} {year} {month} {day} {team} {club} {box}`)도 됩니다
- 폴더 이름에 못 쓰는 글자는 `-` 로 바뀝니다
- `{팀}` 을 안 쓰는 구조면 `팀` 설정을 비워둬도 됩니다
- `{박스}` 를 쓰면 문제 폴더 이름에는 박스를 다시 넣지 않습니다 (중복 방지)
- 메뉴의 '설정 바꾸기' 에서 예시 중에 고르거나 직접 입력할 수 있습니다

그 아래 문제 폴더 이름(`SWEA-4875-...`)은 여전히 `폴더에제목` / `폴더에박스` 를 따릅니다.

### 문제가 여러 페이지에 걸쳐 있어도

문제 박스가 10개 넘어 여러 페이지로 나뉘어 있어도 **알아서 끝까지 넘기면서 전부** 받습니다.
30개씩 보기로 놓고 페이지를 하나씩 넘기며, 보고 계신 탭은 건드리지 않고 새 탭에서 합니다.

```
  1페이지: 10개 읽음 (누적 10/28)
  2페이지: 10개 읽음 (누적 20/28)
  3페이지:  8개 읽음 (누적 28/28)
```

### 폴더 이름에 문제 제목 넣기

```ini
폴더에제목 = 예
```

```
SWEA-1974                →  SWEA-1974-스도쿠 검증
SWEA-1209                →  SWEA-1209-[S-W 문제해결 기본] 2일차 - Sum
```

- 윈도우 폴더명에 못 쓰는 글자(`/ \ : * ? " < > |`)는 `-` 로 바뀝니다.
  그래서 `[S/W ...]` 가 폴더에선 `[S-W ...]` 가 됩니다. **`readme.md` 안의 제목은
  원래대로 `S/W`** 입니다.
- 제목이 아주 길면 50자에서 자릅니다 (경로 길이 제한 때문).
- **이미 만들어 둔 폴더가 있으면 그걸 그대로 씁니다.** 그래서 도중에 설정을 켜고 꺼도
  같은 문제에 폴더가 두 개 생기지 않습니다. 대신 **기존 폴더의 이름은 바뀌지 않습니다.**
  이름까지 맞추려면 아래 `폴더이름갱신` 을 켜세요.

### 폴더 이름에 문제 박스 이름 넣기

```ini
폴더에박스 = 예
```

날짜만 봐서는 그날이 무슨 주제였는지 모를 때 씁니다.

```
SWEA-4875                →  SWEA-4875(Stack2_1)
폴더에제목 도 같이 켜면      →  SWEA-4875(Stack2_1)-[S-W 문제해결 기본] 5일차 - 미로
```

박스 이름은 문제 목록 페이지 제목(`Stack2_1 (3)`)에서 개수를 뺀 부분입니다.
제목과 마찬가지로 못 쓰는 글자는 `-` 로 바뀌고 30자에서 잘립니다.

> 참고 — 한 번 실행은 보통 박스 하나라, 그날 폴더 안에서는 같은 박스 이름이 반복됩니다.
> 그래도 폴더만 보고 주제를 알 수 있다는 게 목적이라면 그게 맞습니다.

### 기존 폴더 이름도 새 설정에 맞추기

```ini
폴더이름갱신 = 예
```

`폴더에제목` / `폴더에박스` 를 바꿔도 **새로 만드는 폴더만** 새 이름이 됩니다.
어제까지 만든 `SWEA-4875` 는 그대로죠. 이걸 켜면 기존 폴더 이름까지 맞춰줍니다.

바꾸기 전에 **무엇이 어떻게 바뀌는지 보여주고 확인**을 받습니다.

```
╭─ 폴더 이름을 바꿉니다 ──────────────────────────────────────╮
│   지금            바꿀 이름                                 │
│   SWEA-4875   ->  SWEA-4875(Stack2_1)-[S-W ...] 5일차 - 미로│
│   SWEA-1222   ->  SWEA-1222(Stack2_1)-[S-W ...] 6일차 - ... │
╰─────────────────────────────────────────────────────────────╯
  폴더 안의 풀이 파일도 같이 따라갑니다.
  이미 커밋한 날짜라면 git 에서 삭제+추가로 잡혀 MR 이 지저분해질 수 있습니다.

> 바꿀까요? [y/N]
```

- 폴더 안의 `.py` 풀이 파일도 같이 따라갑니다
- 바꿀 이름이 **이미 있으면 건너뜁니다** (덮어쓰지 않습니다)
- 설정을 도로 끄고 실행하면 `SWEA-4875` 로 되돌릴 수도 있습니다
- 미리보기(`--dry-run`)에서는 이름을 바꾸지 않습니다

> **커밋한 날짜에는 조심하세요.** git 이 폴더 이름 변경을 삭제+추가로 잡을 수 있어
> MR diff 가 커집니다. 아직 안 올린 날짜에 쓰는 게 안전합니다.

### readme.md 가 필요 없을 때

```ini
readme = 아니오
```

문제 폴더와 sample input 만 만듭니다. **이미 있는 `readme.md` 를 지우지는 않습니다.**

### 크롬 창이 뜨는 게 거슬릴 때 (창숨김)

`settings.txt` 에 이렇게 두면 창이 전혀 뜨지 않고 조용히 돕니다.

```ini
창숨김   = 예
문제목록 = https://swexpertacademy.com/main/talk/solvingClub/problemBoxDetail.do?...
```

> **먼저 알아두실 것** — SWEA 로그인은 오래 유지되지 않습니다. 창을 닫고 한참 뒤에
> 창숨김으로 돌리면 로그아웃 상태라 문제를 못 읽을 수 있습니다.
> 그럴 땐 `창숨김 = 아니오` 로 한 번 돌려 로그인한 뒤 다시 쓰시면 됩니다.

창숨김은 **되면 하고, 안 되면 창을 띄우는** 방식입니다. 막히는 일은 없습니다.
아래 세 경우엔 알아서 창을 띄우고 그 이유를 알려줍니다.

- 아직 SWEA 로그인을 한 번도 안 했을 때 (로그인은 창이 필요합니다)
- `문제목록` 주소가 비어 있을 때 (열린 탭을 봐야 하니까)
- 자동화용 크롬 창이 이미 떠 있을 때 (그 창을 그대로 씁니다)

그래서 `창숨김 = 예` 로 켜두고 그냥 `START.bat` 만 눌러도 됩니다.

### 실제 레포를 건드리지 않고 테스트하기

`--repo` 로 아무 폴더나 지정하면 거기에 똑같은 구조로 만들어 봅니다.

```bash
mkdir _test_out
python swea_sync.py --repo "./_test_out"
```

## 5. 안전장치

- 이미 있는 `readme.md` 는 내용이 같으면 건너뜁니다 (`--force` 로만 덮어씀).
- 이미 있는 input 파일은 다시 받지 않습니다.
- 같은 폴더의 `*.py` 풀이 파일은 절대 건드리지 않습니다.
- 폴더는 `mkdir -p` 방식이라 여러 번 돌려도 안전합니다 (멱등).
- **폴더 이름에 '정답 여부'는 넣지 않습니다.** 문제를 푼 뒤에 상태가 바뀌는데
  폴더는 재사용되므로 이름이 낡은 값으로 굳어버립니다. 게다가 SWEA의 '정답' 배지는
  문제 단위가 아니라 **문제 박스 단위**라(같은 문제가 박스에 따라 다르게 표시됨)
  폴더명에 박아두면 의미가 모호해집니다.

## 6. 문제 해결

**설치가 안 되고 오류가 남**
→ 인터넷 연결을 확인하세요. 사내망이면 프록시 설정이 필요할 수 있습니다.
직접 하시려면 `pip install -r requirements.txt`.

**`방향키 선택을 지원하지 않아 번호 입력으로 진행합니다` 라고 뜸**
-> Git Bash 처럼 윈도우 콘솔이 아닌 터미널에서 실행한 경우입니다. 그대로 번호를
입력해서 쓰셔도 되고, `START.bat` 이나 cmd 창에서 실행하면 방향키를 쓸 수 있습니다.

**한글이 깨져 보임**
→ `START.bat` 이 아니라 `python swea_sync.py` 로 직접 실행한 경우입니다.
`chcp 65001` 을 먼저 실행하거나 `START.bat` 을 쓰세요.

**브라우저 창은 뜨는데 문제 링크를 못 찾음**
→ 십중팔구 **로그인이 풀린 것**입니다. SWEA 로그인은 오래 유지되지 않습니다.
뜬 창에서 다시 로그인하고 문제 박스 페이지를 연 뒤 실행하세요.

**`이 박스에는 N개가 있는데 M개만 읽혔습니다`**
→ 여러 페이지는 알아서 넘기므로 평소엔 안 뜹니다. 그런데도 뜨면 사이트가 잠깐
응답을 못 준 것이니 잠시 후 다시 실행하세요.

**`파이썬을 찾지 못했습니다`**
→ Python 이 설치되지 않았거나 PATH 에 없습니다. python.org 에서 설치할 때
**"Add Python to PATH"** 를 체크하세요.

**`sample input 다운로드 링크를 못 찾았습니다`**
→ SWEA 페이지 구조가 바뀐 경우입니다. 아래로 실제 링크 목록을 뽑을 수 있습니다.

```bash
python swea_sync.py --inspect
```

출력된 링크 목록(또는 생성된 `inspect_*.html`)을 보고
`swea_sync.py` 의 `DOWNLOAD_SELECTORS` 리스트에 맞는 셀렉터를 한 줄 추가하면 됩니다.

참고 — 2026-09-02 기준으로 확인한 실제 SWEA 구조는 이렇습니다.

**문제 목록** (`problemBoxDetail.do`) — 번호·제목·난이도가 전부 여기 있습니다.
그래서 상세 페이지를 열지 않고도 바로가기 링크를 조립할 수 있습니다.

```html
<input type="hidden" id="solveclubId" value="AAAAclubIdAAAA">
<input type="hidden" id="probBoxId"   value="BBBBboxIdBBBB">
<h4 class="club_box_tit">List2_1 (6)</h4>
<div class="widget-box-sub">
  <span class="week_num">4836 .</span>
  <span class="week_text">
    <a href="javascript:clickProblem('CCCCprobIdCCCC','PROBLEM');">제목</a>
  </span>
  <span class="badge badge-a">D2 </span>
</div>
```

**문제 상세** (`problemView.do`) — 다운로드는 평범한 앵커이고,
**링크 텍스트가 곧 원본 파일명**입니다.

```html
<a href="/main/common/contestProb/contestProbDown.do?downType=in&contestProbId=...">sample_input.txt</a>
<a href="/main/common/contestProb/contestProbDown.do?downType=out&contestProbId=...">sample_output.txt</a>
```

문제마다 `sample_input.txt` 이기도 하고 `input.txt` 이기도 한데,
스크립트는 이 이름을 그대로 씁니다 (원본 파일명 유지).

**`브라우저가 뜨지 않았습니다 (http://127.0.0.1:9222)`**
→ 대부분 이전에 쓰던 자동화용 크롬이 아직 살아 있어서입니다. 작업 관리자에서
`chrome.exe` 를 정리한 뒤 다시 실행하세요. 그래도 안 되면 `settings.txt` 의 `포트` 를
9223 등으로 바꿔보세요.

## 7. 조원에게 배포할 때

전달할 것: `swea-sync` 폴더 (`START.bat`, `swea_sync.py`, `ui.py`, `bootstrap.py`,
`settings.txt`, `requirements.txt`, `README.md`, `사용설명서.pdf`).
`profiles/` 폴더는 개인 설정이니 **빼고** 전달하세요.

받는 사람이 할 일은 두 가지뿐입니다.

1. `START.bat` 더블클릭
2. 물어보는 대로 **레포 경로와 조**만 입력 (필요한 설치도 알아서 진행됩니다)

로그인은 각자의 브라우저 프로필(`~/.swea_sync/chrome-profile`)에서만 이뤄지므로
계정 정보는 파일에 전혀 들어가지 않습니다. 배포물에 아이디/비밀번호를 넣지 마세요.
